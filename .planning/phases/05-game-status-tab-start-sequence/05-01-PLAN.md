error_line(msg): 'Select an amino acid first.' -> 'ERROR: Select an amino acid first.'

status_events(prev, curr) — the poll-diff; returns the list of lines to append, IN ORDER level/molecule, then selection, then error:
- prev is None -> [] (first observation SILENT — the start sequence already logged the level line; pitfall 4)
- identical states -> []
- molecule change (molecule_id or molecule_pos/molecule_total or level_pos differs) -> [level_molecule_line(curr)] — exactly ONE line per change tick even if several fingerprint keys moved
- selection change (slot_id differs) -> [selected_line(curr['selected'])]; same-slot re-click -> []; change TO None (deselect) -> [] (selected_line(None) is skipped)
- error None->X -> ['ERROR: X']; X->X (sticky) -> [] (pitfall 3); X->Y (different string) -> ['ERROR: Y']; X->None (cleared) -> []
- 'result' changes -> [] — deliberately NOT fingerprinted in Phase 5 (score lines reserved for Phase 6; pitfall 7)
- fingerprint keys exactly: molecule_id, molecule_pos, molecule_total, level_pos, selected['slot_id'], error — everything else ignored (unknown/extra keys tolerated via .get, the wizard_text consumer precedent)

EVENT_KINDS — a dict mapping kind name -> short role note; the KEY SET is what tests pin:
