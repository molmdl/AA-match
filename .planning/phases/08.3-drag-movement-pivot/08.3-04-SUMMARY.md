**1. [Rule 2 - Missing Critical] Added a view-length guard to `a_per_px`**

- **Found during:** Task 1
- **Issue:** The plan specified fail-closed refusals only for `viewport_h <= 0` / `fov <= 0`. But `a_per_px` reads `view[11]`; a `view` shorter than 12 numbers would raise a bare `IndexError`, bypassing the house fail-closed `ValueError` family (and `drag_world_step` calls `a_per_px` first, so it would never reach `view_camera_to_world`'s own >=9 guard).
- **Fix:** Added `if len(view) < 12: raise ValueError('a_per_px: view must carry >= 12 numbers ...')`.
- **Files modified:** `aamatch/wizard_core.py`
