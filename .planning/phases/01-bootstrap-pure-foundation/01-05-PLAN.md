  <behavior>
**setup_state.py constants:**
- `INTERACTION_TYPES = ["h_bond", "salt_bridge", "pi_stacking", "cation_pi", "hydrophobic", "halogen", "metal"]` (v1 decision: 7 types, salt bridge includes ionic)
- `INTERACTION_MODES = ["exclusive", "block_exclusive", "unset"]`
- `MOLECULES_DEFAULT/MIN/CAP = 2/1/10`; `DIFFICULTY_DEFAULT/MIN/CAP = 3/1/9`
- `DEFAULTS = {"source_mode": "demo", "demo_set_id": "", "upload": None, "molecules_per_level": 2, "difficulty_levels": 3, "interaction_mode": "unset", "allowed_interactions": []}`

**validate_state(state) → NEW dict, never mutates (D3):**
- enums fall back to default on invalid (`source_mode` in {"demo","upload"} else "demo"; `interaction_mode` in INTERACTION_MODES else "unset")
- ints via try/int/except→default, then clamp to [MIN, CAP]
- `allowed_interactions`: keep only members of INTERACTION_TYPES, dedup, store in canonical INTERACTION_TYPES order (equal sets serialize identically)
- `upload`: must be None OR a dict with string `path` and string `sha256` (extra keys dropped) else None
- `demo_set_id`/`source_mode`: str coercion only (manifest membership lands Phase 2/8)

**randomize_state(seed=None) → complete valid state, deterministic under seed (D4):**
- `demo_set_id`: random non-empty string (e.g. `'demo-' + 4 hex chars`); `molecules_per_level`/`difficulty_levels` random within clamp; `interaction_mode` random from INTERACTION_MODES; `allowed_interactions` random non-empty subset (canonical order) regardless of mode (mode governs USE, decided Phase 2/4); `source_mode` stays `"demo"` (upload requires a real file — a randomized state must be usable); `upload` stays None.

**persistence wrappers (module-level `from .setup_state import validate_state` — dependency direction per B8: persistence imports the model, never the reverse):**
- `save_setup_file(path, state)`: `save_container(path, 'setup', validate_state(state))`
- `load_setup_file(path)`: `validate_state(load_container(path, 'setup'))` — validate-on-load normalizes hand-edited files; MUST be idempotent (test case 10).

Testable cases (write ALL as failing tests first):

1. DEFAULTS key-set regression: `set(DEFAULTS)` is EXACTLY the 7 keys (D2 pattern — schema drift fails loudly).
2. validate_state({}) → DEFAULTS deep-equal (missing keys filled).
3. Invalid enum (`interaction_mode: "bogus"`) → default "unset"; valid enums pass through.
4. Int clamping: `molecules_per_level: 99` → 10; `: 0` → 1; `: "x"` → 2 (default); `difficulty_levels: -1` → 1; `: 99` → 9.
5. allowed_interactions: `["halogen", "h_bond", "halogen", "bogus", "metal"]` → `["h_bond", "halogen", "metal"]` (filtered, deduped, canonical order).
6. upload shape: `{"path": 3, "sha256": "abc"}` → None; `{"path": "C:\\x.sdf", "sha256": "ab"}` → kept with exactly keys {path, sha256}; non-dict → None.
7. Non-mutation: validate_state(dirty_state) leaves `dirty_state` unmodified (assert deep-equal to a pre-copy).
8. randomize determinism: `randomize_state(seed=42) == randomize_state(seed=42)`; result has ALL 7 DEFAULTS keys; ints within clamps; enums valid; allowed_interactions non-empty subset in canonical order.
9. **PERSIST-01 round-trip:** build a state with EVERY field at a non-default value (all 7 interaction types listed, unicode demo_set_id e.g. `'démo-β'`, boundary ints at MIN for one field and CAP for another, each of the 3 interaction modes — one subTest per mode, upload dict) → `validate_state` → `save_setup_file(tmp)` → `load_setup_file` → `assertEqual(loaded, original_validated)` — EXACT equality.
10. Validate idempotence: `validate_state(validate_state(x)) == validate_state(x)` for the round-trip states (load re-validates — must not change anything).
11. Refusals (message-asserted, via load_setup_file/load_container): (a) file of random JSON → FormatError containing `not an AA-match file`; (b) container dict with right magic, version 999 written via write_json_atomic → FormatError containing `unsupported` and `Please update AA-match`; (c) container with kind='level_spec' loaded as setup → FormatError containing `expected an AA-match setup file`; (d) truncated/garbage bytes → FormatError containing `could not parse AA-match JSON`.
12. Older-version acceptance: write a container dict with `version: FORMAT_VERSION - 1` (via write_json_atomic) → load_setup_file does NOT raise.
13. Old-file forward-fill: a v0-style setup `data` dict missing `upload` and `allowed_interactions` loads with those keys filled from DEFAULTS (`.get` defaults discipline, B4).
