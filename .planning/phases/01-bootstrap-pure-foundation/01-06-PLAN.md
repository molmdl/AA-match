<feature>
  <name>Level-spec schema + detector_version exact-match gate</name>
  <files>aamatch/level_spec.py, tests/test_level_spec.py</files>
  <behavior>
Module constants: `DETECTOR_VERSION = "det-1"` (EXACT-match gate — bump when detection thresholds/typing change), `LEVEL_SPEC_VERSION = 1` (additive evolution — refuse-newer policy).

`parse_level_spec_dict(d)` — full gate chain, returns the dict (passthrough) on success:
1. Container gate: `check_container(d, 'level_spec')` (from persistence — reuses 01-02's magic/version/kind refusals).
2. Payload `format_version`: `int(data.get('format_version', 1))`; `> LEVEL_SPEC_VERSION` → FormatError containing `unsupported level spec version` (refuse-newer; older accepted).
3. Payload `detector_version`: `!= DETECTOR_VERSION` → FormatError containing `detector` and `stale or newer` — this is the EXACT-match policy: BOTH older and newer detector stamps are refused.
4. Structural minimums: `levels` non-empty list; every level's `difficulty.grid_n >= 1`; every molecule's `grid.n >= 1`; every molecule's `grid.slots` is a list with UNIQUE `slot_id` values.

`make_level_spec_container(data)` = `persistence.make_container('level_spec', data)` convenience re-export for generators/tests.

Testable cases (write ALL as failing tests first):

1. A minimal VALID spec (one level, one molecule, one slot with `slot_id`/`row`/`col`/`aa`/`role`/`can_form`/`grid_pose`) passes parse and returns the SAME dict content (passthrough).
2. Container round-trip: `parse_level_spec_dict(read_json_file(save_container(path, 'level_spec', spec)))` succeeds (persistence integration, kind='level_spec').
3. Stale detector: payload `detector_version: "det-0"` → FormatError containing `detector`.
4. Newer detector: payload `detector_version: "det-2"` → FormatError containing `detector` (P4: this is the case where refuse-newer-only would WRONGLY accept).
5. The two detector tests assert the message contains `stale or newer` (distinct from the format-version message wording — two gates, two messages).
6. Newer payload `format_version: 2` → FormatError containing `unsupported level spec version`.
7. Older payload `format_version: 0` → ACCEPTED (additive policy).
8. Empty `levels` list → FormatError; `levels` not a list → FormatError.
9. `grid_n: 0` → FormatError; `grid.n: -1` → FormatError.
10. Duplicate `slot_id` within one molecule's slots → FormatError mentioning `slot`; same slot_id in DIFFERENT molecules is fine (uniqueness scope is per molecule).
11. **Unknown-key passthrough:** add unknown keys at every level (`data['future_field']`, `level['future']`, `slot['future']`, `grid_pose['rotation']`) → parse succeeds and the unknown keys are STILL PRESENT in the returned dict (P9: additive fields are preserved, not validated away).
12. Missing `detector_version` key → refused (exact-match gate; absence is not 'det-1').
  </behavior>
