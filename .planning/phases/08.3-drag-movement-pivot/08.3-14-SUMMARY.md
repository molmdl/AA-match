- **Third real game harness (PART 0d).** Row 9's `give_up` ends game #2 (`engine.is_over()`), so `drag_move`'s `_require_playing` first statement would short-circuit every step. A third `gamestart.start_game()` (conditional replace) supplies the live picking game without touching rows 1-9.

Observed values (<= 4.75e-07) are inside both, so the stricter number was not needed to make the row pass.
