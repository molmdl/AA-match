Constants: `GAME_VERSION = 1` (payload gate: refuse-newer/accept-older, mirrors level_spec.py:106-114 pattern); `UPLOAD_SET_ID = 'uploaded'` (synthetic set_id for uploaded rows, 04-06 consumes).

`make_game_data(setup, payload, ligand_files=None, created_at='') -> dict`:
- `setup` is re-validated (`validate_state` — idempotent, fail-closed), `payload` is the FULL generator payload (generator.py:714-730 shape — detector_version/format_version/seed/levels).
- Returns the game `data` dict: `{'game_format_version': GAME_VERSION, 'created_at': created_at (informational), 'generator': 'AA-match' (informational), 'setup': <validated setup>, 'seed': payload['seed'] (DUPLICATE convenience; level_spec's is authoritative), 'level_spec': payload (THE TRUTH, verbatim), 'ligand_files': ligand_files or {}}`.
- NO detector_version anywhere at this layer (single home inside the embedded spec — mirroring is the drift PITFALL 11.3).
- NO capability profiles anywhere (charge_signs is a set — unserializable; recomputable — research serialization_shapes).

`parse_game_data(container) -> dict` — the full gate chain, all refusals FormatError with clear messages:
1. `check_container(container, 'game')` — foreign/newer-header/misfiled refusals come free (persistence.py:61-88).
2. `data = container['data']`; `game_format_version` gate: missing/non-int → "game file data is missing or has an invalid 'game_format_version'"; `> GAME_VERSION` → "unsupported game file version %d (expected <= %d). Please update AA-match." (refuse-newer; older accepted with .get defaults — additive-only).
3. `setup = validate_state(data['setup'])` — missing key → "game file data is missing 'setup'".
4. `payload = parse_level_spec_dict(make_level_spec_container(data['level_spec']))` — missing key → "game file data is missing 'level_spec'"; inherits refuse-newer format_version AND exact-match detector_version ("stale or newer game spec - regenerate it with a current AA-match generator") with zero new code.
5. Ligand integrity + source cross-checks over `data.get('ligand_files', {})`:
   - decode every entry (base64 → text); bad base64 → FormatError naming the key.
   - for EVERY molecule in payload['levels'][*]['molecules'][*]: `ligand.source == 'upload'` requires its `ligand.file` key present in ligand_files → missing = "game file is missing embedded content for uploaded molecule %r (key %r)" (an uploaded game without its molecules is unsolvable); `ligand.source == 'demo'` must NOT have an entry → present = "game file embeds content for bundled molecule %r (key %r) -- bundled molecules are package-resolved, never embedded" (single meaning per source).
   - for each present entry with a matching payload molecule: `hashlib.sha256(text.encode('utf-8')).hexdigest()` must equal that molecule's `ligand.sha256` → mismatch = FormatError naming the file + both hashes (64-char-lowercase-hex discipline, manifest.py:94-97).
   - ligand_files entries that match NO payload molecule key → FormatError "game file embeds unused ligand content %r" (no dead weight).
- Returns `{'setup': setup, 'payload': payload, 'ligand_texts': {file_key: text}}`.

`encode_ligand_files(mapping) -> dict`: `{key: base64.b64encode(text.encode('utf-8')).decode('ascii')}` for each `{file_key: record_text}`.
`decode_ligand_files(mapping) -> dict`: inverse; non-decodable → FormatError naming the key. (parse_game_data uses this; exported for Phase 7.)
  </behavior>
