Setup:
  1. Launch a fresh PyMOL. Note `mouse_selection_mode` (command line: `get mouse_selection_mode` — expect 1) and `get button_mode` (expect 0).
  2. Plugins → AA-match. A grid of amino acids + the small molecule appears; the wizard panel shows the header, required interactions, movement buttons, Confirm / Reset to Grid / Done.

PLAY-01 — click-to-select:
  3. LEFT-click an amino acid in the 3D viewer (default 3-Button Viewing — no mode tweaks). EXPECT: its color visibly changes to green; the prompt line names the selected slot/object.
  4. Left-drag on empty space. EXPECT: the camera rotates normally (selection handling did not break viewing).
  5. Click empty space. EXPECT: nothing breaks; the selection stays as it was.

PLAY-02 — move/rotate/adjust + result matches screen:
  6. With an AA selected, press the panel nudge buttons (Left/Right/Up/Down/In/Out). EXPECT: the AA moves ~1 Å per press in the apparent screen direction (In = into the screen; if In/Out feel inverted, note it — cosmetic, detector-neutral).

  8. Keyboard (if the viewer has focus): press LEFT/RIGHT arrows, then w/s/q/e, then comma/period. EXPECT: nudges/rotations IF the Qt focus path delivers them — this is the PROBE; record exactly which keys worked. Panel buttons remain the guaranteed path either way.
  9. Build a pose with an AA ring flat against/above the molecule's aromatic ring (Rotate 90 deg helps align). Press Confirm. EXPECT: the panel shows the result (score fraction, formed/missing types). Then move the AA far away, Confirm again — the result must CHANGE accordingly (near pose ≥ far pose score). This is the on-screen == detected check.
  10. Press 'Reset to Grid'. EXPECT: amino acids return to their grid positions (orientation may persist — recorded decision; only positions replay).

PLAY-03 — switch selection + confirm result:
  11. Click a DIFFERENT amino acid. EXPECT: the first AA's original color restored, the new one green, prompt updates.
  12. Press Confirm with nothing interacting (fresh grid pose after Reset). EXPECT: result shows 0 formed (or the honest fraction).
  13. Also try clicking the small molecule itself and a non-game object (if any loaded). EXPECT: no selection change, no crash.
