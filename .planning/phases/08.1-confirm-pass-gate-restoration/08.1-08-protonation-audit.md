## 2) ATP / NAD — SEPARATE DECISION ROW (do not treat as data changes)

Recorded 08-06 Decision 1 (approved): ATP/NAD charges are explicitly NOT modeled because **ligand phosphates are not charge-typed** (DETECT-04 parity) — verified in code today: `capability._charge_signs` types `−` only for carboxylate-pattern carbons and `+` only for ammonium/guanidinium nitrogens; no phosphorus branch exists. Therefore:

- Shipping CID 5461108 (ATP⁴⁻) or CID 15938971 (NAD net −1) **types nothing** — the M CHG blocks on phosphate oxygens are inert to the detector → typing-dead data churn with zero gameplay effect.
- Making phosphate charge typing real = **new capability branch = a DETECTOR_VERSION event** (exact-match refusal per Gate 4) → new level-spec/bundle regen, needs human approval as its own decision.
- Evidence strength for the physiological charges is documented in §1; both records have verified 3D, so no sourcing obstacle exists *if* the typing decision is ever made. Until then: **ATP and NAD are NOT in the redo-list.**

## 4) Per-file requirements for hand-made MOL2/SDF files

1. **3D coordinates, all non-zero** (build with `obabel ... --gen3d` or equivalent; zero-coords will fail the 3D reality check).
2. **Correct MDL bond orders** — aromatic rings exactly alternating (same law the 02-04 fixtures and current files satisfy); no Kekulé corruption.
3. **Explicit formal charges**: SDF → `M  CHG` block entries on the exact atoms of the §3 table; MOL2 → atom types + charge column. Deprotonated oxygens must carry **no bonded H** (the detector's carboxylate test checks "no O bearing an H"); protonated nitrogens must carry their H (donor typing is fail-closed on bonded H).
4. **Net charge per ligand exactly as in §3** (the 08-01 gate compares formal-charge sums against the manifest).
5. **One record per file** (one `$$$$` per SDF / one `@<TRIPOS>MOLECULE` per MOL2) — bare ions only, never a counterion salt (quinine·HCl CID 91558 is explicitly rejected for this reason).
6. **Stereo preservation**: quinine (natural), glutamate (2S), folate (2S), thyroxine (2S) must match the shipped entries exactly.
7. **Provenance**: the human provides the protocol (confirmed obabel or other) + parameters; provenance is recorded per-row in `docs/DATA_SOURCES.md` with fetch/build date.
8. Every provided file then flows through the 08-01 pipeline: count/charge/descriptor verification (atoms/bonds/formal_charge_sum), single-record assertion, detector-profile re-run (salt-bridge `+`/`−` signs per the laws quoted in §1), solvability re-run for the affected sets, and manifest sha256 re-pin.
