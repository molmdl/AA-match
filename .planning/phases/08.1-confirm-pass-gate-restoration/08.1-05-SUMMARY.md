Same ops (pick + rotate_axis + move_to), same 4.5 Å recipe — only the feature source changed. M1 placements (both conventions coincide there) unaffected.
- **Files modified:** `smoke/smoke_16_tab.py` (`_mol_features` added; the local smoke_07-style `_remap_ligand_bonds` removed).
- **Verification:** SMOKE-16 PASS incl. A7 (`advanced='level' level_pos=2`), C4, F2 passing-confirm end paths.
