  <name>Task 1: scripts/build_demos.py — multi-set bundler + dev-set dry-run proof</name>

  <action>
Create `scripts/` (new top-level dir) with `build_demos.py`. HARD CONSTRAINTS: python3.6-safe (WSL floor; no 3.7+ syntax), stdlib-only, NO pymol/Qt/numpy imports at module level or inside functions, no dataclasses. Gate D only compiles `aamatch/*.py`, so this file is outside the purity gates by design — keep it clean anyway.

CLI: `python3.6 scripts/build_demos.py --spec scripts/demo_specs/<set_id>.json [--fetch] [--dry-run] [--report-only]`.

Spec schema (JSON, validated with refusals naming the bad field):
```
{
  "set_id": "<non-empty str>",
  "tier": "easy|hard|challenge|very_challenging",
  "title": "<non-empty str>",
  "license": "<str; '' only for the dev set>",
  "provenance": {"source_url": "...", "license_url": "...", "fetched": "YYYY-MM-DD", "notes": "..."},
  "entries": [
    {"entry_id": "<non-empty str>",
     "url": "https://..."  OR  "local_path": "aamatch/data/ligands/...",   # one required
     "file": "ligands/<set_id>-<entry_id>.sdf",   # optional override; DEFAULT derived as ligands/<set_id>-<entry_id>.sdf (collision-free: dev set's legacy benzamide.sdf/acetate.sdf kept via explicit override)
     "protonation": "as-recorded",                 # default
     "expect_atom_count": 13,                      # optional corruption guard (from GATE evidence)
     "provenance": {"source_url": "", "pdb_id": "", "entry_doi": "", "paper_doi": "", "plip": "", "notes": ""}  # keys required; DEPTH for curated sets enforced by tests, not the builder
    }
  ]
}
```

Pipeline:
1. Validate spec (structure only; semantic depth lives in tests).
2. For each entry, resolve ligand bytes: `--fetch` → `urllib.request` GET of `url` (User-Agent 'AA-match-build/1.0', timeout 60) written to the target file under `aamatch/data/`; without `--fetch` use the existing target file (or copy from `local_path` to target). REFUSE (fail-closed, naming the source): record count > 1 (split file on `$$$$` lines — "split or pick one state at curation time; never collapse" per sourcing RQ7); V2000 counts-line parse failure; `expect_atom_count` mismatch (fetch-corruption guard).
3. Derive ALL 14 `manifest.REQUIRED_ENTRY_KEYS` from the same bytes: `atom_count`/`bond_count` (counts line cols 0-3/3-6), `heavy_atom_count` (non-H element symbols, stripped+uppercased), `bond_order_counts` (bond-block order digit-string tally, e.g. {"1": 12, "2": 4}), `formal_charge_sum` (M CHG lines), `states_expected` (= record count, asserted == 1), `metal_present`/`halogen_present` (element scan vs DETECT-03 lists {MG ZN FE CA MN CU NI CO CD} / {CL BR I}), `size_class` via `generator._candidate_class` (single home — never re-implement the bucket rule), `sha256` over the target file bytes in the same run, plus `entry_id`/`file`/`format='sdf'`/`protonation`.
4. Set payload = {set_id, tier, title, license, provenance, entries} — nothing else.
5. Assembly: read the committed `aamatch/data/MANIFEST.json` via `persistence.read_json_file` + `manifest.parse_manifest_dict`; replace-or-insert ONLY the target set (all other set dicts untouched); rebuild via `persistence.make_container('manifest', payload)`; RE-PARSE the rebuilt container with `parse_manifest_dict` to prove validity; `--dry-run` prints the derived set payload + a derived==committed comparison per key and exits WITHOUT writing anything; otherwise `persistence.write_json_atomic` to `aamatch/data/MANIFEST.json`.
6. `--report-only`: no network, no writes; read the committed manifest + every spec under `scripts/demo_specs/`; verify each spec's entry files/sha256 match the manifest; print per-set markdown provenance rows (the exact columns 08-09 needs: entry_id, file, molecule, source URL, ID, PDB complex + DOIs, PLIP ref, protonation, halogen/metal, sha256, fetched). Exit non-zero naming gaps on any mismatch.

sys.path: insert the repo root (derived from the script's own location) so `from aamatch import ...` works; import ONLY `persistence` (read_json_file, write_json_atomic, make_container), `manifest` (parse_manifest_dict, REQUIRED_ENTRY_KEYS), `generator` (_candidate_class).

Then write `scripts/demo_specs/demo-dev-1.json`: set_id 'demo-dev-1', tier 'easy', title 'Phase-2 development set', license '', provenance {}, two entries (benzamide, acetate) using `local_path` = the committed files and `file` overrides 'ligands/benzamide.sdf' / 'ligands/acetate.sdf' (legacy names preserved — NEVER rename or rewrite committed dev SDFs), protonation 'as-recorded', provenance dicts with notes 'development fixture built by 02-04 (script-built), NOT curated demo data'.

PROVE the pipeline: run `python3.6 scripts/build_demos.py --spec scripts/demo_specs/demo-dev-1.json --dry-run` — the derived set payload must equal the committed demo-dev-1 payload on every key (the 02-04 manifest counts were constructed from the same lists that wrote the SDFs, so a correct parser reproduces them exactly: benzamide 16/16/{"1":12,"2":4}/heavy 9/charge 0, acetate 7/6/{"1":5,"2":1}/heavy 4/charge −1). Any mismatch = parser bug: fix before committing.
