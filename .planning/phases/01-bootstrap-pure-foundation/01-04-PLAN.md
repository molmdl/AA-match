Testable cases — the EXACT matrix from research R7, one named test each (or a table-driven test with one row per case):

| # | Input | Expected output | Why |
|---|-------|-----------------|-----|
| 1 | `/mnt/c/Users/x/lig.pdb` | `C:\Users\x\lig.pdb` | core conversion |
| 2 | `/mnt/d/data/x.mol2` | `D:\data\x.mol2` | any single-letter drive |
| 3 | `/mnt/C/Users/x` | `C:\Users\x` | drive letter uppercased |
| 4 | `/mnt/c/My Dir/a b.pdb` | `C:\My Dir\a b.pdb` | spaces preserved |
| 5 | `C:\Users\x` (backslashes) | unchanged | guard: already-Windows |
| 6 | `C:/Users/x` (forward slashes) | unchanged | guard |
| 7 | `\\srv\share\x` (UNC) | unchanged | parts[1] != 'mnt' |
| 8 | `data/x.pdb` (relative) | unchanged | guard |
| 9 | `/mnt/c` (no trailing) | unchanged | split yields 3 parts — document the asymmetry |
| 10 | `/mnt/c/` | `C:\` | 4th part empty |
| 11 | `/mnt/abc/x` | unchanged | multi-letter ≠ drive |
| 12 | `/mnt/wsl/x` | unchanged | 'wsl' ≠ single letter (real WSL mountpoint) |
| 13 | `/home/u/x` and `''` | unchanged | non-mount / empty |
| 14 | `C:\x` produced by case 1, fed again | unchanged | idempotence |

Plus: `package_data_path('data', 'x.pdb')` → returns a path that (a) startswith the absolute `aamatch/` package dir and (b) is NOT relative to `os.getcwd()` — assert the result is under `os.path.dirname(aamatch.paths.__file__)`.

  <implementation>
Port `PA-demos.py:59-78` semantics verbatim (research F1-F2):

- `to_windows_path(p)`: guard, NOT an unconditional transform. `parts = p.replace('\\', '/').split('/', 3)`; convert iff `parts[0] == '' and parts[1] == 'mnt' and len(parts[2]) == 1 and parts[2].isalpha()` → return `parts[2].upper() + ':\\' + parts[3].replace('/', '\\')`. ALL other inputs return `p` UNCHANGED. Write the docstring explaining the guard (only WSL mount paths convert; already-Windows and genuine Linux paths pass through) and the case-9 asymmetry.
- `package_data_path(*parts)`: `os.path.join(os.path.dirname(os.path.abspath(__file__)), *parts)` — never `os.getcwd()` (PITFALLS.md:58). Docstring: bundled data must resolve from the INSTALLED plugin location.
- Purity: module-level imports stdlib only (`os`) + purity docstring. NO pymol/Qt.
- Do NOT add drive-letter validation beyond single-alpha, do NOT handle `/mnt//x` specially, do NOT lower/upper anything except the drive letter.
  </implementation>
