# AA-match - A matching game of small molecule and biomolecular interactions based on common (bio-)molecular viewer

## Aim

Develop a pymol plugin of an educational matching game of small molecules and amino acids. 

The game has multiple levels, mutiple difficulties, options of allowed interactions. Each level has a set of small molecules of a specific prtonation state and correct rendering of valence. For each small molecule of the level, show an NxN grid (depends on difficulty) of randomized (capped) amino acid that could form certain interaction with the target molecule. The player will be given a list of targeted interaction to form, and they need to select amino acids from the grid, drag and rotate and adjust it to the interacting atom of the small molecule. The game detect successful match from standard definition of the interaction based on atom types and geometry (e.g. get the number from prolif/plip/binana). No helper lines/dots can be displayed during gamplay so the player can practice working with 3D.

## Requirements of the pymol plugin

0. the user install the plugin as a standard PyMOL plugin. For testing purpose
1. starting the pymol plugin from manual, a setup window will popup
2. the popup window allow the user to change the following parameters:
   * Dropdown to chose which demo set to use (see note 1), or to upload a set of small molecules of right format.
   * Number of small molecules per level (default 2-5, there should be a reasonable cap)
   * Number of difficulty level per game (default 3-5, there should be a reasonable cap)
   * List of interactions to be allowed in the game
      * exclusive: any supporting interactions
      * block exclusive: specific interaction to be selected 
      * if not set, random 
3. the bottom of the popup within would have 7 buttons: (1) Reset, (2) Randomize, (3) Save Setup, (4) Load Setup, (5) Generate and export, (6) Cleanup model (7) Start 
   3.1. Reset: restore the default settings
   3.2. Randomize: randomize setup
   3.3. Save Setup: save the game setup parameters to a file
   3.4. Load Setup: load the setup parameters from a file
   3.5. Generate and export: Only generate all the levels of the game and save this initial state to a file for sharing or later loading of the specific game
   3.6. Cleanup: clear generated by the game that is not in the original object 
   3.7. Start: Start the game  
4. Once the user are happy with the game setup, they click "Start"
5. Clicking start do the following:
   * store thet initial state of the object
   * generate the additional representation based on the setup parameters
   * jump to the Game status tab of the same window
   * countdown 3, 2, 1, then start the game
6. the Game status tab shoud have the following:
   * a generic rolling info box
   * timing after the game started (out of info box)
   * type and number of interactions required to finish this molecule, can be `any` or from the allowed list from (2).
   * import button to import a game prepared by (3.5) Generate and export
   * Hint button: change color of the carbon atoms of the AA that cound form one of the interactions
   * confirm button: confirm the AA placement of the level and start the interaction detection and scoring
   * Skip Mol/give up dropdown button: 
      * skip mol give a warning for confirmation then store only up to current score of the molecule, move to the next molecule. 
      * give up show a warning for confirmation, then end the game at the stage to show the endgame count and message. 
   * save button to save the state of the game as a pymol session and some state info specific for this game so the user can load/checkpoint any time
   * restart button to restart the game from the initial state
   * reset button to place all AA back to the grid
7. In the OpenGL viewer: For each level, for each small molecule, the small molecule is fixed in thet middle of the UI, with the grid of AAs around it beyond a gap.
   7.1. The player navigate in the OpenGL viewer and click on the AA. 
   7.2. Selected AA changed color and get a "selected" status. The player move/rotate it to interact with the small molecule. Once they are happy with this AA, either
         a. click on another AA so another AA change color and the player can move it
         b. click the confirm button to finish this molecule.
   7.3. Once the molecule is finished, in the game status info box calculate and show the molecule's score and total score til the stage, then move to the next molecule
   7.4. Once the level is finished, move to the next level with higher difficulty.
8. After all the levels:
   * show the "score" of interactions of each level reflecting the quality of placement, and total score
   * stop the timer and get the time
   * show a winning message and the time taken, total molecules and levels, and number of skip/give up for the user to finish the game.


Note 1: Provide several options for demo. Demo PDB/SDF should be pre-download citing the source in a doc, with interactions and protonation from known binding database and structure also from a database. Difficulties can groupped by number of interaction type, molecule size, and the number of amino acids in the NxN grid.
